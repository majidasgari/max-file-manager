# Directory Opus feature matrix → max-file-manager

مرجع: امکانات Directory Opus 13 (ویندوز). ستون «فاز» یعنی کِی نوبتش می‌شود؛ هر چیزی که تیک ندارد هنوز پیاده نشده است.

## فاز ۱ — هستهٔ یک فایل‌منیجر روزمره ✅

- [x] دو پنجرهٔ مستقل (مبدأ / مقصد)
- [x] تب در هر پنجره؛ نوار تب با یک تب پنهان می‌شود (تنظیم، پیش‌فرض روشن) و دکمهٔ تب نو در نوار مسیر می‌ماند — ولی در دوپنجره اگر یک طرف چند تب داشته باشد، نوار هر دو طرف می‌ماند تا ارتفاع دو پنل یکی باشد
- [x] سه تنظیم چیدمان تب/سایدبار: جای تب‌ها بالا یا پایین، تب‌های عمودی در سایدبار (فقط نمای تک‌پنلی، بالای Places) و سمت سایدبار چپ/راست نسبت به محور inline — همه پیش‌فرض همان رفتار قبلی؛ تنظیمات → ظاهر و چیدمان
- [x] هم‌رنگ‌کردن ناحیهٔ فایل‌ها با هدر در ۴ سطح (`prefs.contentTone` ۰ تا ۳؛ ۰ = تفاوت امروز، ۳ = دقیقاً هم‌رنگ هدر) — تنظیمات → ظاهر و رنگ
- [x] مرور واقعی پوشه، breadcrumb، بالا/رفرش، Backspace
- [x] سه نمای فهرست (details)، شبکه (thumbnail) و فشرده (compact، مثل Dolphin) با چرخهٔ Ctrl+Shift+V، انتخاب در تنظیمات و ذخیره در قالب هر پوشه
- [x] لیست ستون‌دار با مرتب‌سازی و «پوشه‌ها اول»
- [x] لیست مجازی‌شده — پوشهٔ ۱۰۰هزار فایلی روان بماند
- [x] انتخاب تک/چندتایی (Ctrl، Shift)
- [x] کپی F5 · انتقال F6 · پوشهٔ نو F7 · سطل بازیافت F8 · حذف قطعی Shift+F8 · تغییر نام F2
- [x] نمایش/پنهان‌کردن فایل‌های مخفی (Ctrl+H) — پوشه‌هایی که با `hidden` در `.mfm.json` از فهرست پنهان شده‌اند هم با همین کلید دیده می‌شوند (کم‌رنگ + نشان چشم)
- [x] تم تیره/روشن/سیستم (سیستم روشن/تیرهٔ سیستم‌عامل را زنده دنبال می‌کند)
- [x] ستون‌های نمای details: روشن/خاموش با راست‌کلیک روی سرستون و تغییر عرض با کشیدن لبهٔ سرستون (عرض‌ها ذخیره می‌شوند)
- [x] زیرنویس بندانگشتی: انتخاب فیلدها برای نمایش کوچک و کم‌رنگ زیر نام فایل، هر فیلد در یک خط جداگانه، از منوی ستون‌ها و تنظیمات
- [x] فیلتر نام شناور در پایین-راست پنل، فقط وقتی باز است یا فیلتر فعالی دارد؛ دکمهٔ قیف جای آن در نوار آدرس است (Ctrl+F بازش می‌کند، Esc می‌بندد)
- [x] انتخاب چندتایی با کشیدن مستطیل روی فضای خالی (Ctrl نگه‌داشتن، انتخاب قبلی را اضافه می‌کند)
- [x] چسباندن تصویر از کلیپ‌بورد (Ctrl+V) به‌صورت فایل در پوشهٔ جاری، با نام یکتا و انتخاب خودکار فایل تازه
- [x] عرض پنل پیش‌نمایش/ادیتور در تک‌پنجره و دو‌پنجره با کشیدن جداکننده تغییر می‌کند و ذخیره می‌شود
- [x] اندازهٔ کاشی‌های نمای بندانگشتی با Ctrl + چرخ ماوس (۸۰–۲۴۰px، همان تنظیم tileSize)
- [x] منوی راست‌کلیک گروه‌بندی‌شده: چهار زیرمنوی «عملیات فایل / پوشه و نمایش / مسیر و سیستم / برچسب و جزئیات» + «خروجی فهرست»؛ منوی اصلی کوتاه می‌ماند و با هاور/کلیک باز می‌شود؛ اگر یک طرف جا نباشد زیرمنو در سمت دیگر باز می‌شود و روی منو نمی‌افتد
- [x] پنجرهٔ «ویژگی‌ها» تب‌بندی‌شده مثل Dolphin (منو یا Alt+Enter):
- [x] تغییر آیکون پوشه از تب «عمومی» پنجرهٔ ویژگی‌ها (باز شدن همان انتخاب‌گر رنگ/آیکون)
  - **عمومی**: آیکون/بندانگشتی، نام قابل‌ویرایش (تغییر نام با Enter/بلور)، نوع، MIME، «باز کردن با» + «تغییر…»، مسیر کامل با کپی، اندازهٔ خوانا و بایت دقیق، ابعاد تصویر، هدف پیوند، سه زمان
  - **دسترسی‌ها**: جدول مالک/گروه/بقیه با «می‌تواند مشاهده و تغییر دهد / فقط مشاهده» (chmod واقعی)، اجرا‌پذیر، مالکیت با نام و شناسه، مجوز پیشرفتهٔ سه‌رقمی، لینک سخت و inode/device
  - **چکیده**: چکیدهٔ مورد انتظار + جای‌گذاری از کلیپ‌بورد، محاسبهٔ MD5/SHA-1/SHA-256/SHA-512 با کپی و نشان «مطابقت دارد/ندارد»
  - **جزئیات**: نوع/محتوا/اندازه/ابعاد، چهار زمان، برچسب رنگی، امتیاز ستاره و توضیح (همه در `.mfm.json` همان پوشه)
  - کپی مسیر و «نمایش در فایل‌منیجر سیستم» در پایین پنجره
  - هر تغییر (مجوز، برچسب، ستاره، توضیح) فهرست پشت پنجره را فوراً دوباره می‌خواند؛ برچسب رنگی هم در ردیف فهرست و هم روی کاشی شبکه دیده می‌شود
- [x] فونت رابط کاربری از تنظیمات → ظاهر: هفت فونت اوپن‌سورس امبدشده (Vazirmatn، Inter، Noto Sans، Noto Sans Arabic، Source Sans 3، IBM Plex Sans، JetBrains Mono) به‌صورت چیپ با نمونهٔ زنده؛ هاور/فوکوس روی هر چیپ همان لحظه نمونهٔ بزرگ پایین را با آن فونت نشان می‌دهد (بدون تغییر تنظیم) و کلیک آن را اعمال می‌کند؛ به‌علاوهٔ هر فونت نصب‌شدهٔ سیستم با نام آزاد، و «افزودن فونت» از فایل ttf/otf/woff/woff2 که در `userData/fonts` کپی می‌شود و بعد از ری‌استارت هم می‌ماند؛ خانوادهٔ تکی خودکار با وزیرمتن برای پوشش فارسی ترکیب می‌شود
- [x] دکمه‌های پنجره (بستن/مینیمایز/ماکزیمایز) با چهار حالت **پیش‌فرض / مک (McMojave) / ویندوز / مینیمال** و انتخاب سمت چپ/راست؛ فقط با تایتل‌بار خود برنامه (با قاب سیستم‌عامل غیرفعال است)
- [x] تم‌های رنگی (پیش‌فرض، شرابی، نیمه‌شب، زغالی، جنگلی، یاسی، نعنایی، شنی، آسمانی، گلی) روی حالت روشن/تیره؛ از تنظیمات → ظاهر و رنگ با پیش‌نمایش رنگ
- [x] نشان‌کردن پوشهٔ انتخاب‌شده در سایدبار از ستاره یا منوی پوشه (و برداشتنش)؛ بدون انتخاب، پوشهٔ باز نشان می‌شود؛ کشیدن پوشه از پنل و رها کردن آن روی سایدبار (هر جای ستون، از جمله بخش Places) هم آن را نشان می‌کند — حین درگ کل سایدبار هایلایت می‌شود و زیر Places پیام «پوشه را رها کن تا نشان شود» می‌آید
- [x] نوار آبی «پنل فعال» فقط در چیدمان دوپنجره دیده می‌شود
- [x] تغییر عرض بین دو پنجره در حالت دوپنجره با کشیدن خط جداکننده (Splitter) با ماوس؛ دوبار کلیک عرض را به ۵۰/۵۰ برمی‌گرداند
- [x] «همیشه نشان بده» از منوی راست‌کلیک: یک فایل/پوشه حتی با خاموش‌بودن «فایل‌های مخفی» دیده می‌شود (نقطه‌دار، نامِ فهرست نادیده‌گرفتن، یا پوشهٔ `hidden`)؛ در `.mfm.json` همان پوشه ذخیره می‌شود و با یک نشان چشم در فهرست مشخص است
- [x] مدیر فایل پیش‌فرض سیستم: امکان بررسی و تنظیم برنامه به عنوان مدیر فایل پیش‌فرض سیستم (از تنظیمات → راه‌اندازی) — لینوکس با `xdg-mime` و MIME `inode/directory`; ویندوز با verb کاربر در `HKCU\Software\Classes\{Directory,Drive}` (دابل‌کلیک روی پوشهٔ دسکتاپ همین برنامه را باز می‌کند) و دکمهٔ «بازگرداندن به ویندوز» مقدار قبلی را برمی‌گرداند؛ verb فقط روی `Directory` و `Drive` نوشته می‌شود (نه `Folder`، که ریشهٔ همهٔ شل‌نیزم‌اسپیس‌هاست) تا فقط پوشه‌های واقعی باز شوند و Control Panel / This PC در Explorer بمانند؛ دکمهٔ Control Panel هم در هدر برنامه هست
- [x] کوچک‌کردن به سینی و بستن به سینی (فقط با تک‌نمونه)، با منوی «نمایش/خروج» در سینی
- [x] نشان پیوند نمادین: یک زنجیر نازک و کم‌رنگ کنار نام (نه بج)
- [x] ساخت میانبر از منوی راست‌کلیک، با دو مقصد «در همین پوشه» و «روی میزکار» (چند انتخاب یک‌جا)؛ روی ویندوز فایل `.lnk` واقعی با `shell.writeShortcutLink` (بدون نیاز به Developer Mode) و روی لینوکس/مک سیم‌لینک «Link to <name>» — نام تکراری هرگز بازنویسی نمی‌شود و `shortcut` در MCP همان مسیر را صدا می‌زند
- [x] میانبر یک **برنامه** روی ویندوز همان شکلی است که Explorer می‌سازد: نام بدون پسوند («notepad - Shortcut.lnk» — ویندوز `.exe` را همه‌جا نشان می‌دهد)، هدف = خود برنامه، «Start in» = پوشهٔ برنامه (برنامه‌ای که DLL/دادهٔ کنارش را می‌خواند فقط از همان‌جا اجرا می‌شود) و آیکون از خود برنامه؛ سند این آیکون را نمی‌گیرد تا آیکون نوع فایل بماند و `.bat`/`.msi` نام کامل خود را نگه می‌دارند. ردیف‌های منو برای برنامه «ساخت میانبر کنار برنامه» و «ارسال میانبر به میزکار» می‌شوند، و روی پوشهٔ فقط‌خواندنی (Program Files) پیام روشن با پیشنهاد میزکار می‌آید
- [x] کلید منوی کیبورد (Menu / Shift+F10) همان منوی راست‌کلیک انتخاب را باز می‌کند
- [x] راست‌کلیک داخل انتخاب چندتایی، منوی مخصوص همان انتخاب است: «باز کردن n مورد»، اجرای فایل‌های اجراپذیر، کپی/انتقال/تغییر نام گروهی/فشرده‌سازی/حذف، کپی مسیرها، `SHA-256`، میانبر، مقایسه (دو فایل)، افزودن موسیقی و تبدیل تصاویر — هر ردیف با تعداد؛ ردیف‌های تک‌فایلی (باز کردن با، پیش‌نمایش، تغییر نام، ویژگی‌ها) پنهان می‌شوند
- [x] راست‌کلیک روی فضای خالی یعنی خودِ پوشهٔ باز: «ویژگی‌های این پوشه…»، «انتخاب همه» و «چسباندن» در همان منو؛ Alt+Enter بدون انتخاب هم همان پنجرهٔ ویژگی‌های پوشه را باز می‌کند
- [x] «باز کردن با…» از فهرست برنامه‌های .desktop همین سیستم + «برنامهٔ پیش‌فرض»؛ اگر پیش‌فرض باز نشود، پنجرهٔ انتخاب باز می‌شود — روی ویندوز از `SHAssocEnumHandlers` (همان فهرست Explorer، شامل اپ‌های Store مثل Photos و Paint) با آیکون واقعی هر برنامه و اجرا با `IAssocHandler::Invoke`
- [x] پیش‌نمایش متن با رنگ‌آمیزی (JSON/کد)؛ فایل‌های آفیس (docx/xlsx/pptx/odt/ods/odp) پیش‌نمایش ندارند و با برنامهٔ پیش‌فرض باز می‌شوند
- [x] نوار بندانگشتی گالری همیشه تصویر فعال را وسط خودش می‌آورد
- [x] باز کردن فایل با برنامهٔ پیش‌فرض سیستم
- [x] ویرایشگر متن داخلی برای `txt`/`md`/`log` و فایل‌های بدون پسوند: Enter یا دوبار کلیک بازش می‌کند، F4 متن/کد را در ادیتور، تصویر را در گالری و ویدئو را در پلیر پیش‌نمایش باز می‌کند، ذخیرهٔ اتمیک با Ctrl+S
- [x] پنجرهٔ مستقل ادیتور/نمایشگر دکمه‌های کوچک/بزرگ/بستن را از همان تنظیم تایتل‌بار اپ می‌گیرد و سمتشان فیزیکی است (چپ یا راست، مستقل از RTL)؛ فاصلهٔ سربرگ هم به همان سمت می‌رود تا نام فایل زیر دکمه‌ها نیفتد
- [x] تعویض فایل در ادیتور باز: با انتخاب یک فایل متنی در پنل کنارِ ادیتور (کلیک/فلش) یا بازکردن فایل تازه، فایل قبلی اگر تغییر کرده باشد خودکار ذخیره می‌شود و فایل تازه در همان ادیتور باز می‌شود (بدون از دست رفتن تغییرات)
- [x] جهت خودکار در متن خام: هر خط از اولین حرف قوی خودش راست/چپ می‌چیند (فارسی راست‌چین، انگلیسی چپ‌چین، خطوط ترکیبی درست) — همان رفتار بلوک‌های ادیتور مارک‌داون؛ پیش‌نمایش پنل کنار و خروجی PDF هم همین قاعده را دارند
- [x] ریشه‌ها: `/` و خانه و دیسک‌های جانبی (لینوکس) · حروف درایو (ویندوز)

## فاز ۲ — سرعت و راحتی روزمره ✅

- [x] Ctrl+A انتخاب همه · Esc پاک‌کردن انتخاب و صافی
- [x] نوار فرمان: چیدمان دلخواه، حالت «فقط آیکون / آیکون و متن / فقط متن»، و در عرض کم دکمه‌های جامانده به «…» می‌روند (بدون بریدن یا اسکرول بی‌صدا) · قابل خاموش‌کردن از تنظیمات → نوار ابزار؛ در حالت خاموش همهٔ فرمان‌ها در منوی ⋮ سربرگ هستند
- [x] پیمایش با کیبورد مثل Krusader: ↑/↓ ردیف، Shift+↑/↓ بازه، PgUp/PgDn/Home/End، ← پوشهٔ بالاتر، → باز کردن (در نماهای شبکه و فشرده فلش‌ها خانه‌به‌خانه می‌روند)
- [x] تعداد خطوط نام در نمای شبکه قابل تنظیم (۱ تا ۴ خط؛ کاشی با آن بلندتر می‌شود)
- [x] تاریخچهٔ رفت‌وبرگشت در هر پنجره (Alt+← / Alt+→)
- [x] صافی زندهٔ همان پوشه در نوار مسیر (Ctrl+F)؛ Enter اولین نتیجه را باز می‌کند
- [x] نمای شبکه با بندانگشتی واقعی تصاویر (پروتکل داخلی `mfm://`)
- [x] بندانگشتی SVG، WebP، AVIF، GIF، BMP و ICO در نمای شبکه (Chromium رسم می‌کند؛ `nativeImage` فقط PNG/JPEG را می‌شناسد)
- [x] نمای شبکه سایزبندی دارد: کاشی کوچک/متوسط/بزرگ/بزرگ‌تر و ۱ تا ۴ خط نام؛ بندانگشتی و گلیف پوشه با کاشی بزرگ می‌شوند
- [x] آیکون پوشه‌ای که دلفین در `.directory` یا ویندوز در `desktop.ini` گذاشته، خوانده و همان‌جا نمایش داده می‌شود (آن فایل‌ها فقط خوانده می‌شوند)
- [x] آیکون فایل و پوشه از آیکون‌ست **Pure که داخل برنامه embed شده** می‌آید (data URL، بدون وابستگی به سیستم‌عامل)؛ در تنظیمات می‌شود آیکون‌ست سیستم‌عامل یا گلیف‌های خطی را انتخاب کرد — دور آیکون‌ها کادر نیست؛ آیکون پوشهٔ تعیین‌شده در `.directory` (دلفین) یا `desktop.ini` (ویندوز) هم خوانده و نشان داده می‌شود
- [x] رنگ پوشه از واریانت‌های رنگی Pure استفاده می‌کند (قرمز/نارنجی/زرد/سبز/آبی/بنفش/صورتی/خاکستری) و با آیکون‌ست خطی همان گلیف رنگ‌شده می‌ماند
- [x] رنگ فایل از همان پالت: در فهرست و کاشی یک دایرهٔ رنگی قبل از نام؛ رنگ در `.mfm.json` پوشه ذخیره می‌شود و آیکون فایل تغییر نمی‌کند
- [x] انتخاب‌گر آیکون کامل Pure: تمام ۳۰۴۴ آیکون ۶۴px داخل باندل، دسته‌بندی (مکان‌ها/انواع فایل/برنامه‌ها/دستگاه‌ها/وضعیت/ویجت‌ها)، سه اندازهٔ نمایش و جست‌وجوی نام؛ رنگ‌های پوشه فیروزه‌ای و مشکی هم اضافه شد

## فاز ۵ — یکپارچگی با میزکار (شروع شد)
